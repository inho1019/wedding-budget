# 결혼 예산표 (Wedding Budget)

PDF 예산표를 그대로 재현한 결혼 예산 관리 앱입니다. React + Vite + Tailwind CSS로 제작했습니다.

## 기능

- **엑셀처럼 자동 계산** — 세부 항목(노란 영역)만 수정하면 소분류 · 대분류 · 전체 예산이 자동으로 반영됩니다
- **대분류 / 소분류 / 항목 추가** — `+` 버튼으로 자유롭게 확장 가능
- **이름 변경** — 대분류·소분류·항목명을 더블클릭으로 수정
- **세션 쿠키 저장** — 변경사항이 브라우저에 자동 저장 (브라우저를 닫까지 유지)
- **공유 링크** — 현재 예산을 압축해 URL 해시에 담아 복사하면 정합성이 유지된 채 공유
- **JSON 다운로드** — 데이터를 파일로 백업

## 데이터 구조

```
대분류 (결혼식, 신혼여행, 혼수, 집, …)
├── 소분류 (웨딩홀, 혼주, 가구, …)
└── 세부 항목 ← 사용자가 수정 (예랑+예신 / 모은 돈)
```

각 항목은 `예랑+예신`(수입으로 내는 금액)과 `모은 돈`(저축한 돈) 두 열로 입력하며,
`합계 = 예랑+예신 + 모은 돈`으로 자동 계산됩니다.

## 시작 방법

```bash
yarn install
yarn dev      # 개발 서버 (http://localhost:5173)
yarn build    # 프로덕션 빌드
yarn preview  # 빌드 결과 미리보기
```

## 기술 스택

- React 18 + TypeScript
- Vite 5
- Tailwind CSS 3
- Zustand (전역 상태 관리)
- lz-string (공유 URL 압축)

## 프로젝트 구조 (FSD)

```
src/
├── app/            # 앱 진입 · 프로바이더 (상태 동기화)
├── pages/          # 페이지 컴포넌트 (결혼 예산표)
├── features/       # 비즈니스 기능 (예산)
│   ├── model/      # 타입 · 계산 · 저장 · 상태(store)
│   └── ui/         # UI 컴포넌트
└── shared/         # 재사용 가능한 유틲·UI
    ├── lib/        # 포매팅
    └── ui/         # 공통 컴포넌트
```
